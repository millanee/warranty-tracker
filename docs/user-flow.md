# Primary User Flow

## Add a Product

1. User opens the app.
2. User sees the product overview.
3. User selects "Produkt hinzufügen".
4. User enters the product information.
5. User enters the purchase date.
6. User optionally enters the delivery date.
7. User selects whether the product is new or used.
8. User optionally enters manufacturer warranty information.
9. User takes or selects a receipt photo.
10. User saves the product.
11. The app calculates the relevant expiration dates.
12. The app schedules local reminders.
13. The product appears in the overview.

## View a Product

1. User opens the product overview.
2. User selects a product.
3. User sees purchase details, receipt and expiration dates.
4. User can edit or delete the product.
5. User can open the complaint checklist.

## Empty State

1. User opens the app without saved products.
2. The app explains its main benefit.
3. The app displays a clear "Produkt hinzufügen" action.
