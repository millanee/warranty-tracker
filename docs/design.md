# MVP UI Design

The initial user interface for Warranty Tracker was designed in Figma.

## Design Goal

The interface should feel friendly, approachable and trustworthy while keeping
the focus on purchase receipts, warranty periods and statutory consumer rights.

## Included Screens

1. Empty product overview
2. Product overview
3. Add-product form
4. Product details
5. Warranty and statutory rights information

## Main User Flow

1. Open the application
2. Add a product
3. Enter purchase and warranty information
4. Add a receipt
5. Save the product
6. View the product overview
7. Open product details and relevant expiration dates
8. Access general consumer information

## Design Principles

- Friendly and approachable visual style
- Clear distinction between manufacturer warranty and statutory rights
- Strong focus on relevant expiration dates
- Large and understandable touch targets
- Consistent reusable UI components
- Responsive and scrollable mobile layouts
- Offline-first application concept

## Design System

### Typography

The design uses the Inter typeface with reusable styles for:

- Screen titles
- Section titles
- Card titles
- Body text
- Captions
- Large expiration dates
- Button labels
